forge exposes FreeCAD's kernel to an LLM through the Model Context Protocol: documents, sketches with constraints, features, fasteners, gears, FEM runs and a turntable render the agent can look at to check its own work. A cookbook of proven build sequences and a vision verification loop keep the model honest.

The project grew into Cejanics, an AI-native CAD tool built on the same foundation.
