This site is a place for the things that don't fit in a CV: robots I have retrofitted, agents I run for myself, and notes from building the small home infrastructure that hosts all of it.

It is a static Astro build. The files sit on a Debian laptop at home, Caddy serves them, and a Cloudflare Tunnel carries them out; no port on my router is open. Everything else on that machine stays on a private Tailscale network.
